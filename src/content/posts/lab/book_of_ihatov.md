伊哈托布语 (l'Ihatov) 是一种黏着语，并具有部分屈折语的特征。

其创作核心是“融合东西洋音韵美”，其中“东洋”即为日语，“西洋”即为拉丁语。故本语言采用了大量日语与拉丁语的底层词汇，并加以拉丁与希腊源词缀，以力求实现东洋与西洋语言的音节美感的融合。

在设定上，这种语言诞生于未来社会，以未来对古典美的“文艺复兴”为目标，故在古典表达与新兴事物中取得平衡，同样是本语言力求探讨的目标之一。

以下文本可能并非本语言的最终版本。由于编辑时间跨度较大，文中部分内容可能有所冲突，以下均以正文内容而非示例为准。

# §1 字母表、音系与正字法

## §1.1 字母表

伊哈托布语字母表基于标准拉丁字母表，并另有增加一些变音字母，详见 §1.2.6。

## §1.2 音系与正字法

伊哈托布语没有音节结构上的限制。重音由语境确定，不区分任何意义。

### §1.2.1 音系

以下为伊哈托布语的音系：

| 辅音表 | 唇  | 齿龈 | 龈腭 | 硬颚 | 软腭 | 声门 |
| ------ | --- | ---- | ---- | ---- | ---- | ---- |
| 塞音   | p b | t d  |      |      | k ɡ  | ʔ    |
| 鼻音   | m   | n    |      |      |      |      |
| 闪音   |     | ɾ    |      |      |      |      |
| 擦音   | f v | s z  | ɕ ʑ  |      |      | h    |

### §1.2.2 字母表

伊哈托布语的文字大致遵循一字一音原则。以下列出伊哈托布语中，部分字母与 IPA 的对应关系。没有提到的字母，其读音都与 IPA 中对应字母所表示的音一致。

- C c /k/ 或 /s/
- J j /ʑ/
- Q q /k/
- R r /ɹ ~ ɾ/
- X x /ks/
- Y y /j/

⟨r⟩ 一般发 /ɹ/，但闪音 /ɾ/ 也是可以接受的变体；

⟨y⟩、⟨w⟩ 不被允许出现在词首，分别用 ⟨i⟩、⟨u⟩代替，如 ioma /joma/（读）、uarawa /waɹawa/（笑）。

### §1.2.3 字母组合

在伊哈托布语中，还存在一些字母组合表示其他的发音：

- sc /ɕ/
- tc /tɕ/
- zc /ʑ/
- dc /ʑ/

对于这四个字母组合，仅当它们后面接 ⟨i⟩、⟨e⟩ 或 ⟨y⟩ 时这样读，如 sciaga /ɕjaga/ （完成）、hatcia /hat͡ɕia/ （胡闹）。其他情况下则分开读出，如 musculus /musculus/ （肌肉）。特别地，如果 ⟨c⟩ 上加了软音符，则它们在任何情况下都读成这样的字母组合。

- ph /ɸ/ → /f/
- vh /β/ → /v/
- th /θ/ → /t/
- dh /ð/ → /d/
- ng /ŋ/ → /n/

这几个字母组合多用于标记词源，对应在来源语言中如前一个的发音，而在伊哈托布语中的发音为后一个。除 ⟨ph⟩ 外，所有“辅音 + h”的字母组合也都读如辅音本身。

另外，除在词尾且前面不为 a/o/e 时，“i(y)/u(w) + 元音 V”的字母组合全部连读作 /jV/ 或 /wV/，例如 sciabura /ɕjabuɹa/（吸）、arukuia /aɹukwia/（人行道）；

但是，如果 i(y)/u(w) 和后面的元音跨两个构词成分，或结尾是变格后缀 (-ia / -ius / -ium），则不连读，例如 izumiarium (izumi-ar-ium, 医务室) 、tappuryo（tappury-o, 满的）。

### §1.2.4 长音

长音都使用字母双写表示，如 pekoppa /pekopːa/ （鞠躬）。字母组合的长音双写其第一个字母，如 bisscioryo /biɕːjoɹio/ （潮湿的）。

特别地，⟨k⟩、⟨s⟩ 的长音也可以分别写作 ⟨ck⟩、⟨cs⟩，如 kiracka /kiɹakːa/ （闪耀）。

### §1.2.5 ⟨c⟩ 的发音

字母 ⟨c⟩ 在 ⟨e⟩、⟨i⟩、⟨y⟩ 前读作 /s/，如 glacium /glasium/ （冰）；而在 ⟨a⟩、⟨o⟩、⟨u⟩ 前读作 /k/，如 curo /kuɹo/ （黑色的）。后面没有元音字母的 ⟨c⟩ 都读作 /k/，如 milc /milk/（牛奶）。

⟨c⟩ 也可以用于表示长音，此时它表示的长音与后面的 ⟨c⟩ 的发音一致，如 sicco /sikːo/ （干燥的）。

### §1.2.6 变音符号

可以用变音符号表示字母与一般的发音不同。

- 软音符可以应用在 ⟨c⟩ 上，使其变为 ⟨ç⟩，使其在任何地方都发 /s/。

以下的都只运用于元音字母：

- 尖音符可以
  - 在后面为元音时，使元音后加上 /ʔ/，如 cóargua /koʔaɹɡua/（争辩）；
  - 使其后面的辅音变为长音，如 écorosa /ekːoɹosa/；
  - 使其前面的 ⟨c⟩ 发为 /k/，如 vincé /vinke/ （胜利，不及物形态一般将来时）。
- 曲音符可以使字母的发音变为 /a/，如 öutputa（输出，英语 output）。
- 钝音符可以使字母的发音变为 /ə/。

### §1.2.7 外来词与专有名词

当一个外来词被借入伊哈托布语，它就按照伊哈托布语的规则转写。

不过，如果仅作为专有名词，则保留原拼写。如日语的“雪(ゆき)”作为外来借入词写作 iuki，但专有名词，如人名“雪(ゆき)”则写作 Yuki。

# §2 语法框架

## §2.1 语序

伊哈托布语中一般使用的语序是 SVO。

然而，伊哈托布语具有完整的格标记与动词变化体系，允许了其他语序的存在且不会造成歧义，因而其他语序在强调等用法时也经常使用。例如，通常在想要强调句中的谓语或宾语时，会将其放到最前面。

## §2.2 论元结构

### §2.2.1 关于及物与否的思考

伊哈托布语中的动词没有强制分为及物、不及物动词，抑或自、他动词。

为了规避动词被强行规定及物与不及物形态都存在时，与使动语态产生的表述矛盾（例如，“飞”的及物形态是没有意义的），伊哈托布语将使动形态提升为第三种基本的动词变化形态，从而使得每个动词都可以存在以下三种基本的形态：不及物、及物、使动。

然而，“飞”的问题依然没有解决。显然，其第一种和第三种用法是有意义的，但第二种却仍没有意义（注意，例如“魔法师飞起了扫帚”这样的表述，实际上仍是使动意）。

对于这个问题，伊哈托布语并不做解决。对于及物与使动形态间的冲突，我们这样定义：及物形态表达“直接影响”义，而使动形态为“间接引发”义。如果一个动词在某一形态上无意义，则它可以不存在。例如，“飞”存在不及物、使动两种形态，但在标准语境下不存在及物形态。其可能只在高度专业化或艺术化的语境下被使用。

“我们升起了烟花”，毕竟是比“我们使烟花升起了”可爱。

### §2.2.2 分裂不及物性

伊哈托布语中的动词采取分裂不及物系统。这意味着，伊哈托布语认为，对于不及物动词，有的唯一论元（主语）与及物动词的受事（宾语）相似，有的则与其施事（主语）相似。这种系统由阿利亚语中形容词作表语的现象发展而来。我们将及物动词的施事，以及与及物动词的施事相似的不及物论元定义为主格；及物动词的受事及其他的不及物论元则定义为宾格。例如：

> Kasumi arukal. 霞（主格）正在走路。（主动走路）
>
> Kasumim mawaral. 霞（宾格）正在转动。（被动地转动；可能是因为某物而转动，但未作说明）

不及物论元的格有时候还可以区分具体的意义。例如：

> Shigure auditá. 时雨听了。（主动地倾听某物，但未作说明）
>
> Shigurem auditá. 时雨听到了。（未主动去听，只是听见）

### §2.2.3 基本的格

伊哈托布语中有以下几个基本的格：主格、宾格、与格、属格，另外还有方位格系统。方位格系统将在后文详述。不同的名词，根据其结尾不同，变格方法也不同。

第一变格法是最基础的变格法，适用于大部分以辅音结尾的词：

| 原形 | sol（太阳） | ment（工具) |
| ---- | ----------- | ----------- |
| 主格 | sola        | menta       |
| 宾格 | solem       | mentem      |
| 与格 | solos       | mentos      |
| 属格 | soli        | menti       |

第二变格法适用于以元音结尾的词：

| 原形（主格） | izumi（泉） | natsu（夏天） | facie（脸） | cacao（可可） | exity（外面） |
| ------------ | ----------- | ------------- | ----------- | ------------- | ------------- |
| 宾格         | izumim      | natsum        | faciem      | cacaom        | exitim        |
| 与格         | izumios     | natsus        | facies      | cacaos        | exitios       |
| 属格         | izumii      | natsui        | faciei      | cacaoi        | exitii        |

对于 -a、-us 和 -um 结尾的词，采用第三变格法：

| 原形（主格） | orbia（轨道） | hominus（人类） | aurum（金） |
| ------------ | ------------- | --------------- | ----------- |
| 宾格         | orbiam        | hominùm         | aurùm       |
| 与格         | orbias        | hominòs         | auròs       |
| 属格         | orbiae        | hominì          | aurì        |

对于 -is 结尾的词，采用第四变格法：

| 原形（主格） | audis（音乐） | synthesis（合成） |
| ------------ | ------------- | ----------------- |
| 宾格         | audiem        | synthesiem        |
| 与格         | audios        | synthesios        |
| 属格         | audiei        | synthesiei        |

### §2.2.4 格的标记方式

伊哈托布语中也允许使用另一种方式将一个词变格：使用助词。每个格也都有对应的助词作为替代：

| 格   | 后缀     | 介词 |
| ---- | -------- | ---- |
| 主格 | -a       | á    |
| 宾格 | -m / -em | é    |
| 与格 | -os      | pros |
| 属格 | -i       | i    |

例如，onyma（名字）的与格为 onymos；但也可以使用助词 pros 标记，写成 pros onyma。此时这个变格的词不需要加上格后缀。需要注意的是，当要变格的部分有定语时，格后缀只能放在被修饰的词上，但格助词可以放在这整个部分前面。如：

> aruka ty itus（格后缀标记在 itus 上）
>
> pros aruka ty itus（格助词标记整个短语）

当一个成分中有多个词并列时，格后缀每个都要标记，而格助词不用。例如，以下都代表“大地与天空”的宾格：

> teraos et soraos / pros tera et sora

格标记在伊哈托布语中的使用是有限制的：第一，在成分太长，以至于添加格后缀并不明显时，通常使用助词来进行格的标记。第二，对于外来的人名、地名等专有名词，也使用格助词。第三，用于强调其格属性。例如：

> É irum, sa essida!?
>
> 这东西，你把它吃掉了！？

### §2.2.5 方位格系统

在伊哈托布语中，“方位格”不仅指某一个特定的格，而是指一套表示方位以及其衍生出的各类抽象意义的格系统。在方位格系统中，使用格进行的方位表达是非固定的，所有表示方位的格都可以动态生成。这种生成方式的灵感来源于古希腊语，其中介词后接的词若格不同，所表示的意义也不同。

基本的方位格后缀由两个部分构成：方位后缀与方向后缀，各自均可对应一个介词。

方位后缀代表主语在该事物上发生、存在的位置，是静态的：

| 方位后缀 | 后缀 (V/C)   | 介词   |
| -------- | ------------ | ------ |
| 整体     | -Ø           | Ø      |
| 上       | -n / -an     | ana    |
| 下       | -hyp / -yp   | hypo   |
| 前、早   | -pre / -re   | pre    |
| 后、晚   | -post / -ost | post   |
| 内、里   | -in / -in    | in     |
| 外、表   | -x / -ex     | ex     |
| 对、面   | -cont / -ont | contra |
| 临近     | -d / -ad     | ad     |
| 通过     | -pèr / -èr   | per    |
| 伴随     | -tto / -(C)o | etto   |
| 身份     | -de / -ide   | ide    |

方向后缀代表主语在该事物、该位置的方向，是动态的：

| 方向后缀 | 后缀 (V/C) | 介词 |
| -------- | ---------- | ---- |
| 静止     | -is / -is  | nis  |
| 从、自   | -r / -er   | de   |
| 至、向   | -os / -os  | pros |
| 为、给   | -bo / -obo | ob   |
| 超、过   | -ne / -one | one  |

当方向后缀是“静止”时，可以省略方向后缀。例如，通过 + 静止 (-pèris) 省略为 -pèr，依然表示通过、经过、使用某物。

每个方位格后缀组合都直接加在词根后，其划分方法参见 §3.2.1。特别的是，为了方便，第四变格法的词在方位格变形时与词根不同，多了一个 -i：biologis → biologi- 而非 biolog-。

每种后缀都有两种形式，当词根以 i、y 以外的元音结尾时，用 V-形式；以 i、y 或辅音结尾时，用 C-形式。特别地，以 y 结尾时，词根把 -y 改为 -i 再加 V-后缀。如表示“从……外”：

> momo → momoxer (momo-x-er, 桃子)
>
> logistus → logist- → logistexer (logist-ex-er, 专家)
>
> anemity → anemiti- → anemitixer (anemiti-x-er, 自由)

伴随方向后缀的 C-形式双写其前面的辅音字母，如：radicus → radic- → radicco (radic-co, 连带着根)。

以下为几个方位格搭配例：

> arabus → arabanis (arab-an-is, 在树上) / araban
>
> flumen → flumenèris (flumen-èr-is, 通过河流) / flumenèr
>
> sora → soranone (sora-n-one, 超过天空之上)

## §2.3 动词的变形

### §2.3.1 动词的形态

伊哈托布语中，每个动词都存在三种形态：不及物形、及物形、使动形。这三种形态的使用决定了一个句子应该如何构成。

**不及物形**的动词只有一个论元，其为主语，根据其逻辑意义确定其主语使用主格还是宾格。这是伊哈托布语的分裂不及物性导致的，详见 §2.2.2。

**及物形**的动词一般有两个论元，施事者为主语，受事者则为宾语。如果这个动词在逻辑上可以有与格宾语，则也会有第三个论元。例如：

> Hazuki vidia aquoslaimem. 叶月看水母。
>
> Hazuki atawis Rinem do hanes. 叶月给凛一根羽毛。

**使动形**的动词，使动者用主格，间接宾语使用与格，而谓语（被使动的施事者）为宾格。例如：

> Yūko nemuris Natsukiem. 优子（主语）让夏纪（宾语，宾格）睡觉。
>
> Natsuki cagis Yūkoos coimom. 夏纪（主语）让优子（间接宾语，与格）闻雾气（直接宾语，宾格）。
>
> Yūko icis Natsukios possafem. 优子（主语）让夏纪（间接宾语，与格）打（夏纪）自己（直接宾语，宾格）。

### §2.3.2 动词的词根

在词典中，每个动词默认的原型都是以 -a 结尾的，去掉这个 -a 得到的便是动词对应的词根。

以下以 corosa（杀）为例，其词根为 coros-，示范变形的模式。

### §2.3.3 形态的变形

形态是伊哈托布语动词变形的第一步。

上文提到，伊哈托布语中每个动词都可以选用三种形态：不及物形态、及物形态、使动形态。具体的变化将在下文总述。

### §2.3.4 时的变形

伊哈托布语中存在过去时、现在时、将来时三个时，用于说明动作的发生时间。具体的变化将在下文总述。

### §2.3.5 体的变形

伊哈托布语中存在多个体，来进一步说明动作的发生情况，分别为：

- 一般体，用于无特指时的情况；
- 完成体，表示动作已完成；
- 进行体，表示动作正在进行；
- 未然体，表示动作尚未发生，但被计划、预计或必然将发生；
- 自动体，仅用于不及物形，表示动作由程序、机器、自然规律等其他事物控制而自动发生。

时与体在三个形态中的变化分别如下：

| 不及物形 | 一般体 | 完成体   | 进行体  | 未然体  | 自动体   |
| -------- | ------ | -------- | ------- | ------- | -------- |
| 过去时   | corosu | corosuta | corosul | corosux | corosqui |
| 现在时   | corosa | corosata | corosal | corosax | corosqua |
| 将来时   | corose | coroseta | corosel | corosex | corosque |

| 及物形 | 一般体  | 完成体    | 进行体   | 未然体   |
| ------ | ------- | --------- | -------- | -------- |
| 过去时 | corosiu | corosiuta | corosiul | corosiux |
| 现在时 | corosia | corosita  | corosil  | corosix  |
| 将来时 | corosie | corosieta | corosiel | corosiex |

| 使动形 | 一般体  | 完成体    | 进行体    | 未然体    |
| ------ | ------- | --------- | --------- | --------- |
| 过去时 | corosus | corosutas | corosulis | corosuxis |
| 现在时 | corosis | corositas | corosilis | corosixis |
| 将来时 | coroses | corosetas | coroselis | corosexis |

### §2.3.6 词根以 -i 结尾的动词的变形

部分动词以 -ia 结尾，其变形方式略有区别。以 -ia 结尾的动词变形如下，以 moria（去世）为例，其词根为 mori-：

| 不及物形 | 一般体 | 完成体  | 进行体 | 未然体 | 自动体  |
| -------- | ------ | ------- | ------ | ------ | ------- |
| 过去时   | moriu  | moriuta | moriul | moriux | moriqui |
| 现在时   | moria  | moriata | morial | moriax | moriqua |
| 将来时   | morie  | morieta | moriel | moriex | morique |

| 及物形 | 一般体 | 完成体  | 进行体 | 未然体 |
| ------ | ------ | ------- | ------ | ------ |
| 过去时 | moryu  | moryuta | moryul | moryux |
| 现在时 | morya  | morita  | moril  | morix  |
| 将来时 | morye  | moryeta | moryel | moryex |

| 使动形 | 一般体 | 完成体   | 进行体   | 未然体   |
| ------ | ------ | -------- | -------- | -------- |
| 过去时 | morius | moriutas | moriulis | moriuxis |
| 现在时 | moris  | moriatas | morilis  | morixis  |
| 将来时 | mories | morietas | morielis | moriexis |

### §2.3.7 词根以 -c 结尾的动词的变形

部分动词以 -ca 结尾，其变形方式略有区别。以 -ca 结尾的动词变形如下，以 vinca（胜利）为例，其词根为 vinc-。总体上，不及物形态 -c- 发为 /k/，而其他形态为 /s/：

| 不及物形 | 一般体 | 完成体  | 进行体 | 未然体 | 自动体  |
| -------- | ------ | ------- | ------ | ------ | ------- |
| 过去时   | vincu  | vincuta | vincul | vincux | vincqui |
| 现在时   | vinca  | vincata | vincal | vincax | vincqua |
| 将来时   | vincé  | vinceta | vincél | vincéx | vincque |

| 及物形 | 一般体 | 完成体   | 进行体  | 未然体  |
| ------ | ------ | -------- | ------- | ------- |
| 过去时 | vinciu | vinciuta | vinciul | vinciux |
| 现在时 | vincia | vincita  | vincil  | vincix  |
| 将来时 | vincie | vincieta | vinciel | vinciex |

| 使动形 | 一般体 | 完成体   | 进行体   | 未然体   |
| ------ | ------ | -------- | -------- | -------- |
| 过去时 | vinçus | vinçutas | vinçulis | vinçuxis |
| 现在时 | vincis | vincitas | vincilis | vincixis |
| 将来时 | vinces | vincetas | vincelis | vincexis |

### §2.3.8 语气的变形

语气可以用来表达更加精确的语义，通过直接通过附加语气后缀来表示，并可以伴随具体的语调变化。最主要的三种语气：感叹、祈使与疑问的语气后缀分别为 -ze、-yo 和 -no，直接加在进行了前面三步变化的动词后。特别地，使动形动词的感叹语气最后变为 -zze，如 corosis → corosizze。

仅需把动词进行语气变化，就可以直接构成感叹句、祈使句和一般疑问句，当然也可以视情况调整语序，强调句子中的某个部分。例如：

> Makoto cackonaze! 真太帅了！
>
> Fusayo. 躺下吧。
>
> Sa vidtáno? 你看了吗？（现在完成体）

Ze、yo 和 no 也可以在句末单独使用，构成相应句式。如：

> Cackona Makoto ze! 太帅了，真！
>
> Vidtá sa no? 看了吗，你？

### §2.3.9 动名词

在动词词根前加上 i- 就可以将其变为动名词，如 vida（看）的名词为 ivid。

特别地，加上了以 -iza 后缀的动词需将 -iza 变为 -sis，如 izumiza（涌现）的名词为 izumisis；以 iV- / uV- 起始的动词需要把 iV- / uV- 改为 yV- / wV-，如 ioma（读） - iyom、uarawa（笑） - iwaraw。

动词词根加上后缀 -i 同样也可以派生出名词，但表示一个与之相关的事物，二者语义有细微的差别：例如 vida 可以派生出 ivid 和 vidi，前者表示“看”这件事，后者则表示一个与“看”相关的概念，即“视频”。

## §2.4 形容词的变形

### §2.4.1 用作定语的形容词

伊哈托布语中，形容词都以 -o 结尾。去掉 -o 的是形容词对应的词根。

这种用法也是形容词直接用为定语时的形式。

### §2.4.2 用作表语的形容词

形容词用作表语时，在形容词原形后加上助动词 na，之后按照不及物形态动词的方式进行变形。其主语都用主格。如：

> Terra montoidona. 地面是厚的（montoido）。（现在一般体）
>
> Astra kirackontá. 星星已经闪耀（kiracko）过了。（过去完成体）

特别的，当形容词以 -no 结尾时，去掉 -no 后加 na。如：

> Voican acana. 烟是红色（acano）的。

### §2.4.3 副词

形容词用作副词时，在词根后面加上 -y。如：

> Ya bravy dostá. 他做得好（bravo）。
>
> Sakura amaidy uarawal. 樱正在开心地笑着。

### §2.4.4 形容词的名词形式

与动词一样，形容词的名词形式也在词根前加上 i-，如 brevo（短暂的） → ibrev、kitsuno（紧的）→ ikitsu。

以 iV- / wV- 起始的形容词亦需要把 iV- / wV- 改为 yV- / wV-，如 iowano（弱小的）→ iyowa。

### §2.4.5 形容词的指小与指大

可以使用中缀 -in- 和 -on- 分别表示指小与指大的含义。这两个中缀加在最后一个 -o 前。如：

> puro（干净的）→ purino（有点干净的）/ purono（非常干净的）
>
> suzucio（凉爽的）→ suzucino（略微凉爽的）/ suzuciono （非常凉爽的）
>
> samuo（寒冷的）→ samuino（略冷的）/ samuono（很冷的）

### §2.4.6 形容词的比较级与最高级

表示比较级与最高级时，则也有对应的后缀或助动词，如：

| 原型   | centro     | atsuo     | okio    |
| ------ | ---------- | --------- | ------- |
| 比较级 | centrioro  | atsuioro  | okioro  |
| 最高级 | centriccio | atsuiccio | okiccio |

同样，它们也可以作表语，各自的原型将上表 -o 改为 -a 即可，其分别相当于加上了助动词 iora 和 iccia。表示比较时，被比较的事物使用“超、过”方向后缀。例如：

> Sapporo Asahikawa-ne okioro. 札幌比旭川大。

特别地，当句子里本已有一个“超、过”方向的成分时，已有的应该用介词表示格：

> Aria longona gaiane. 火星离地球远。
>
> Aria gaiane longiora one luna. 火星比月球离地球远。

表示最高级时同理：

> Tracaria puriccia. 这地方最干净。
>
> Tracaria puriccia edone. 这地方比其他的都干净。

## §2.5 助动词的用法

### §2.5.1 助动词

助动词是辅助动词进行语意变化的动词，例如 éa / eta（被）、ila（能）等。当一个动词需要助动词时，有两种用法：一，其可以以词根形式在整个动词的前方出现，后面加上一个撇号，但 un- （不）和 é- （被）不加。如：

> il'aruka 能走路
>
> ésasa 被刺

当撇号两边是两个辅音时，读出时加上一个介音 /ə/。助动词的词根在动词前可以多个堆叠，未造成语义区别时顺序不定，但永远只用一个撇号，如：il'ésinia 能被刺。需要大写时，撇号之后的首字母大写。

二，其可以作为一个单独的动词使用。如：

> ila tam Aruka 能走路
>
> eta tam Sasa 被刺

这实际上是宾语从句，参见 §2.9.1。

一般不在动词前堆叠三个以上的助动词，特别是会造成语义区别时，同样的意义用第二种用法表示。如：

> atil'ésasa = ata tam il'Ésasa 开始能被刺
>
> ilat'ésasa = ila tam at'Ésasa 能开始被刺

### §2.5.2 否定助动词

否定助动词为 una。特别的，否定助动词加在动词和形容词前时，不需要加上单引号分割。加在其他助动词前面时，un- 永远在最前面。例如：

> Asuka unésasa. 明日香没有被刺。
>
> Traca unil'sciaga. 这还没能完成。
>
> unsalo ya 不伤心的他
>
> Ya unsalona. 他不伤心。

### §2.5.3 被动助动词

被动助动词为 eta，加在动词上时可以用来构成一个被动句，使得原句的主格与宾格互换。放在动词前面时，形态为 é-，且不加单引号。以上文的例句为例：

> Yūko nemuris Natsukiem. 优子让夏纪睡觉。
>
> Natsuki énemuris Yūkom. 夏纪被优子让睡觉。

需要注意的是，对于一个有间接宾语的使动形态的动词的句子，是主格和与格（间接宾语）互换：

> Yūko icis Natsukios possafem. 优子让夏纪打自己。
>
> Natsuki éicis Yūkoos possafem. 夏纪被优子（搞得）让（夏纪自己）打自己。

## §2.6 代词与限定词的用法

### §2.6.1 人称代词

在伊哈托布语中有三个人称的代词，不分数。第一、第二、第三人称的词根分别是 u-、s-、i-，部分变格形式如下：

| 格           | 第一人称 | 第二人称 | 第三人称 |
| ------------ | -------- | -------- | -------- |
| 主格（原型） | ua       | sa       | ia       |
| 宾格         | uem      | sem      | iem      |
| 与格         | uos      | sos      | ios      |
| 属格         | ui       | si       | ii       |

当人称代词需要单用且没有变格时，以其主格形态作为原型。如：

> structura i ia 有关他的框架

### §2.6.2 限定词

限定词可以用于限定所指的范围，或者作为代词使用，有 traco（这）、sodo（那）、edo（其他）、ceno（所有）等。可以直接用作定语：

> traco arboria 这些森林

以 -o 结尾的限定词，用作代词时去掉 -o 再变格。主格则需要加上 -a。如：

> Soda longona. 那很远。

限定词可以与构词词根结合，构成所指更加细致的限定词，此时优先去除限定词后的元音。例如：

> tracaria (traco + -aria) 这地方
>
> soditus (sodo + -itus) 那人

### §2.6.3 限定词 oi 与特殊疑问句

Oi 是一个限定词，单独使用时为“何，什么”的意思。与限定词结合时，就可以构成特殊疑问句中的疑问代词。如：

> oitus (oi + -itus) 谁 (= oi itus)
>
> oiria (oi + -aria) 哪 (= oi aria)

特别的是，“什么”直接用 oi 表示即可。其变格为：

| 主格（原型） | oi  |
| ------------ | --- |
| 宾格         | oim |
| 与格         | ois |
| 属格         | oii |

将动词变为疑问语气，再如：

> Azusa essieno oim? 梓吃了什么？
>
> Erika oiriis no? 绘梨香在哪？（oi + -(a)rium + -is：何 + 地方 + 方位格）
>
> Traco avus oii no? 这只鸟是谁的？

### §2.6.4 反身代词

Saf 是反身代词，意思是“自己”。这个代词可以有三种用法：第一，前面加上其他代词，表示“……自己”。例如：

> uasaf 我自己、sasaf 你自己、iasaf （第三人称）他自己
>
> Ua cowia uasafem. 我吓我自己。

第二，前面加上格对应的介词，表示对应格自身。这种方式可以用来规避歧义。如上文的例句：

> Yūko icis Natsukios prossafem. 优子让夏纪打（夏纪）自己。

由于“夏纪”是与格，所以与格对应的介词 pros 加上 saf 的 prossaf 指与格（夏纪）自己，而非“优子”。第三，前面直接连接一个词，通常用于强调。此时前面加连字符。例如：

> Soditus cowia soditus-safem. 那人害怕（那人）自己。

## §2.7 数词与数的表达

以下是伊哈托布语中基本的十个数词：

| 基数词     | 序数词 | 前缀 (A/B)       |
| ---------- | ------ | ---------------- |
| nilo (no)  | nilor  | nil- / nili-     |
| do         | dor    | hit- / hito-     |
| rei (re)   | reior  | fut- / futa-     |
| mi         | mior   | mit- / mi(C)-    |
| fa         | for    | iot- / io(C)-    |
| sol        | solor  | its- / itsi-     |
| la         | lor    | mut- / mu(C)-    |
| ci         | cior   | nan- / nana-     |
| otto (tto) | ottor  | iat- / ia(C)-    |
| con        | conor  | cocon- / cocono- |

### §2.7.1 基数词的用法

基数词可以用于直接表示物品的个数：

> mi itus / itus la mi 三个人

特别地，后面使用强调标记 la 的用法，在代词和限定词后可以省略：

> Traca-mi (= traca la mi) uakúwona. 这三个很期待。

也可以像代词一样使用，表示数个前述事物，如：

> Mia uacúwona. 三个（人）很期待。

### §2.7.2 序数词的用法

序数词在对应的基数词后添加 -or 的后缀，并替换其前面除 i 以外的元音，其结果参见上表。序数词同样可以直接修饰名词、代词、限定词，以及像代词一样使用，但不与强调标记 la 一起使用：

> cior cado 第七个角
>
> Dor itus sciaga. 第一个人完毕了。
>
> Dora sciaga. 第一个完毕了。

### §2.7.3 数的前缀

在伊哈托布语中，有一套数的对应前缀，其部分词源来源于日语。这套前缀有 A、B 两种形式，一般 A 形式用于后面接元音时，B 形式用于接辅音时。

这套前缀的最主要用途是用于构成数字相关的词，例如：

> hitodimensia / futadimensia / middimensia 一维、二维、三维
>
> hitator / futator / mitor 独轮车、自行车、三轮车

### §2.7.4 其他数字的构成

直接使用基数词与 deco（十）、heca （百）等其他数词连接，组成较大的数字。为一百、一千等时，1 可以省略。个位的部分用基数词。各部分用连字符连接。如：

> mega (1,000,000)
>
> conkilo (9,000)
>
> mideco-con (39)
>
> ottoheca-condeco-fa (894)

对于千位以上的部分，一个数级中的以其基数词直接依次排列。在一个部分的开头时，8 读成 otto，其他时候读成 tto。2 都读成 re；0 都读成 no。如：

> rettonokilo (280,000)
>
> dodofakilo-solheca-deco-fa (114,514)

为了便捷，个级的部分也可以直接排列，尤其是对于百以上的数。因此，也有：

> rettono (280)
>
> dodofakilo-soldofa (114,514)

### §2.7.5 小数

小数部分在表述小数点的连词 dot 后，按照基数词的方法逐位读出：

> nilo dot micisol (0.375)
>
> con dot nodo (9.01)

### §2.7.6 分数

分数先读分子，再读分母，中间用 in 连接。

> do in deco-la (1/16)
>
> deco in kilo-do (10/1001)

### §2.7.7 量词

一部分名词可以作为量词使用，用于更加精确地描述物品的数量。量词作为定语的使用分为三个部分：数词、量词、-ty。例如：

> do-monton-ty arbum 一堆木材
>
> rei-terron-ty cacaotura 两板巧克力

量词也可以直接代替前面提到的物品：

> Rei terrona éessia. 有两板被吃了。

一个特殊的用法是，“量词 + ty”代表存在很多这样的物品：

> terron-ty cacaotura 很多板巧克力

## §2.8 特殊句式

### §2.8.1 判断句

判断句中使用系动词 na 来连系主语和表语，按照其及物的形态来变形。主语使用主格，而表语使用宾格。如：

> Avus nia animalùm. 鸟是动物。
>
> Fructus nie florùm. 果实曾经是花朵。

其其他变化形式也与动词相同，如：

> Fructus nieno florùm? 果实曾经是花朵吗？
>
> Cusus unnia animalùm. 草不是动物。

### §2.8.2 存在句

表示“存在，有”的动词是 ira，用其不及物形态。存在句的主语默认是宾格，如：

> Ioriem atrantais iral.
>
> 伊织正在海上。
>
> Yayoim tracis uniral.
>
> 弥生不在这里。

### §2.8.3 疑问句

在 §2.3.7 和 §2.6.3，已经分别描述了一般疑问句和特殊疑问句的构成方法。下面进一步阐述其构成。**一般疑问句**：把动词变为疑问语气。问句以肯定形式提问时，使用 factoy（是）或 noy（不是）回答。

> Ia casuckal no?
>
> 你是在开玩笑吧？
>
> Factoy. / Noy.
>
> 是的。 / 不是的。

问句以否定形式提问时，还可以使用 gaty（对）或 anty（不对）来回答：

> Ia uncasuckal no?
>
> 你不是在开玩笑吧？
>
> Factoy. / Noy.
>
> 是的（我在开玩笑）。/ 不是的（我没在开玩笑）。
>
> Gaty. / Anty.
>
> 同意（我没在开玩笑）。/ 不同意（我在开玩笑）。

Gaty 和 anty 表示对带有否定的提问，是否认为其答案为真；而 factoy 和 noy 则表示对问句提问的事实本身，是否认为其为真。在肯定形式提问时，这两对回答也可以混用。**特殊疑问句**：使用 oi 组合出的代词替代句中的未知部分。

> Megumi niano oim?
>
> 惠是谁？
>
> Sciagano sa oioris? / Sciagano sa oi tempois?
>
> 你想在什么时候完成？

**选择疑问句**：在每一个选择的部分前添加 oi，中间用 al（或）连接。

> Sa sukia oi Anzum al oi Momom?
>
> 你喜欢杏子还是桃子？

**附加疑问句**：在句子结尾添加 oi，另外可以再重复一次前面的动词。与上文是非问句一样可以有两组回答方式。

> Corosieno iem sa, oi (corosieno)?
>
> 你会杀了他的，是吧？

## §2.9 从句的用法

从句是作为句子中的一个成分的短句。所有的从句起始都必须大写。

### §2.9.1 名词性从句

这样的从句可以用于充当主语、宾语等，甚至可以加上方位格等来充当状语。从句前面使用形式代词 ta 代替。从句在句中也是在 ta 上进行变格，其变格参考人称代词。对于从句的代词，不使用格的介词。如：

> Ta Cacaotura écula culinis unéantya.
>
> 把巧克力装在箱子里是不会被反对的。

### §2.9.2 定语从句

定语从句可以用来修饰一个主语或者谓语。有两种用法：一，放置在被修饰部分前，并在其后添加介词 ty；二，放置于被修饰部分后，在其前添加介词 te。无论何种情况，从句起始都需要大写。如：

> Écula culinis ty cacaotura éessita.
>
> Cacaotura te Écula culinis éessita.
>
> 装在箱子里的巧克力被吃掉了。

强调时，前后可以用逗号隔开。无论放在哪里都可以用 te 和 ty。所以也可以写成：

> Cacaotura, Écula culinis ty, éessita.
>
> Te Écula culinis, Cacaotura éessita.

被修饰部分在定语从句中默认处于主语或宾语的位置，视语境而定。当被修饰部分在定语从句中不处于主语或宾语位置时，在定语从句中使用不定代词 o 替代这一部分。其变格为：

| 主格（原型） | o   |
| ------------ | --- |
| 宾格         | om  |
| 与格         | os  |
| 属格         | oi  |

例如：

> magius te Atawi os carem
>
> 被给予房子的魔法师（魔法师为与格）
>
> corus te Haemus izumiza or
>
> 血液所来源的心脏（心脏为“从、自”方向方位格）

### §2.9.3 同位语从句

同位语从句进一步说明所修饰的部分。同位语从句前使用同位语标记 le 连接。强调时，前后可以用逗号隔开。如：

> Dosia, le Horia sodo dragonem, dusotis uos iem.
>
> 挖那条龙的工作让我创作了它。
>
> Gaia, le Ui umaria, nia coryo astram.
>
> 地球，我们的家乡，是颗少有的星球。

# §3 借词框架

诚如伊哈托布语的设计理念，“融合东西洋音节美的尝试”，实际上构词法才是这门人造语言的创意核心。笔者在构建的过程中力求在美学、合理性与系统性之间取得平衡，从而最大程度向“伊哈托布”的创造者——宫泽贤治先生致敬。

## §3.1 借词总论

### §3.1.1 借词的来源

本语言的词语大多来自以下三个来源：代表“东洋”的日语；代表“西洋”的拉丁语及古希腊语；代表“现代”的英语——或者更加精确地说，现代世界的通用语言。

代表东西洋的日本及拉丁-希腊来源不必多说，英语的出现则是为了达成伊哈托布语在传统与现代间的平衡。伊哈托布语必须确保自己融合足够的美感，却又不至于完全沦为一具徒有美感的人造化石，英语的引入正可以弥补这一点。

举一个例子，如何使用东西洋的两个来源对译这些概念：应用程序（app）、压缩（zip）、排除计算机故障（debug）、分布式拒绝服务攻击（DDoS）？自然，汉语做到了这一点，但概念越复杂，就需要越精确的定义，实际上大部分人也并不会在日常生活中说“排除计算机故障”，而是直接使用英语的“debug”（DDoS 就更是这样了）。因此，或许显得强词夺理，为了实现古今这一维度的平衡，这就是部分英语专业借词存在的意义。

以上各种来源的借词，通过下文将会介绍的转换方法处理后，便可以进入伊哈托布语使用。

### §3.1.2 借词来源的取舍

当然，对于同一个概念，这三个来源必然会有不同的词语来对应。例如，对于“星”这一意义，就至少有日语的星(ほし)、拉丁语的 stēlla、古希腊语的 ἄστρον (ástron)、英语的 star。应该选择哪一种？

对此——笔者本人，也就是伊哈托布语的作者，个人的偏好自然是第一要素；不过，其是否具有美感（或者说更接近“伊哈托布”的童话感）也是重要的一环。上面的四个词中，伊哈托布语最终选择了 stella (stēlla) 和 astri (ἄστρον)。

除开这些较为抽象的标准，另一个标准是其是否适合进行下文将要进行的词根转换，是否具有足够的标志性。例如，对于“口”，没有选取拉丁语 ōs (ōris)，而是日语口(くち)；对于“目”，没有选取日语目(め)，而是拉丁语 oculus。

### §3.1.3 对原词语的重分析

为了构建更多的风味与特征，伊哈托布语会对于部分借词进行重分析，与后文将对于拉丁语词本身带有的语法性别的消除不同，这种操作仅基于词本身的形式。

比如，对于日语来源的词，若其以 -a 结尾，则进行重分析：例如，对于日语草(くさ)，将 kusa 的 -a 重分析为词尾，词根改写为 cus-，并加上相应的语义性别（第三变格法）后缀 -us，便成了伊哈托布语的 cusus。

## §3.2 词根与语义性别

### §3.2.1 词根、词尾与词的原形

在伊哈托布语中，大部分词都有着词根与词尾的划分。具体例子如下：

| 词类                 | 原形    | 词根    | 词尾 |
| -------------------- | ------- | ------- | ---- |
| 第一变格法名词       | milc    | milc-   | Ø    |
| 第二变格法名词       | momiji  | momiji- | Ø    |
| 第三变格法名词 (-a)  | philia  | phili-  | -a   |
| 第三变格法名词 (-us) | piscius | pisci-  | -us  |
| 第三变格法名词 (-um) | salum   | sal-    | -um  |
| 第四变格法名词       | polis   | pol-    | -is  |
| 形容词               | suzucio | suzuci- | -o   |
| 动词                 | separaa | separa- | -a   |

词根是进行词的变形及派生的核心。

出现在词典中的一个词的形态是词的原形。名词的原形根据其遵循的变格法不同而不同；形容词的原形以作定语时的 -o 的形式结尾；动词则以其不及物形现在时一般体形式为原形，以 -a 结尾。

### §3.2.2 语义性别的分类

在伊哈托布语中，名词采用的变格法是根据语义性别来区分的。

没有语义性别的名词，各自归入第一、第二变格法或第三变格法（-a 结尾）。

与人、动植物、器官等生命物体相关的名词，一般归入第三变格法，以 -us 结尾，如 novitus（年轻人）、animalus（动物）、tsubasus（翅膀）。

与材料、地点、建筑等非生命、人造物体相关的名词，一般归入第三变格法，以 -um 结尾，如 lapum（岩石）、librarium（图书馆）、mercarum（部门）。

与动态过程、人为定义的系统、学科等概念体系相关的名词，一般归入第四变格法，以 -is 结尾，如 audis（音乐）、prosis（进步）。

第三、四变格法的规律不是严格的，并不包括所有相关的词语。实际上，其归类也取决于词源和构词法，详见后文。

然而，这样的分类也并未完全脱离语法性别分类。不过，通过观察名词原形的词尾，可以很容易地知道它应当采取哪种变格法，因为所有 -a、-us、-um、-is 这些特殊的词尾均不与第一、二变格法重合，因此不会导致变格法选择的困惑。

## §3.3 日语来源借词的转换

下文“日语”均指现代日语。我们选择不进一步遁入古日语的深渊，而是从表面上保留现代日语已有的词形，故有不少规定都是为最大限度平衡词源和现代词形而规定的。为了方便，以下原词语日文与平文式罗马字间的转换不再赘述，所有的操作均对应平文式罗马字。

大部分假名的平文式罗马字均可与伊哈托布语正字法直接对应，但为了拼写美观，部分假名的对应做了调整。以下只列出转写到伊哈托布语时与对应罗马字不同的假名：

- し shi - sci
- ち chi - tci
- しゃ・しゅ・しょ sha / shu / sho - scia / sciu / scio
- ちゃ・ちゅ・ちょ cha / chu / cho - tcia / tciu / tcio
- か・く・こ ka / ku / ko - ca / cu / co (除动词词根末尾)
- せ se - ce
- や・ゆ・よ ya / yu / yo - ya / yu / yo (词中); ia / iu / io (词首)
- わ wa - wa / ua (词首)

伊哈托布语中不存在长短音的对立，因此所有原有的长音都会在伊哈托布语中被改为短音。

### §3.3.1 名词的转换

由于日语音系的特殊性，大部分名词均会直接归入第二变格法或第三变格法 -a 结尾。不过，需要注意的是以 -a 结尾的名词，例如草 (kusa)、桜 (sakura) 会被重分析，结果分别为 cusus、sakurus。

### §3.3.2 形容词的转换

对于形容词，直接取其词干并加上 -o，如寒い (samui) - samuo、短い (mijikai) - mijicao。特别地，以 -shii 结尾的，shi 只用写作 ci 而非 sci：涼しい (suzushii) - suzucio、楽しい (tanoshii) - tanocio。

形容动词同理：好き (suki) - sukio、ガチ (gachi) - gatcio。特别地，词干以 -ka 结尾的，改为 -co：爽やか (sawayaka) - sawayaco、朗らか (hogaraka) - hogaraco。

形容词的转换不进行重分析：白い (shiroi) - sciroo、空っぽ (karappo) - carappoo。

### §3.3.3 动词的转换

日语中的动词分为多类，而大部分动词都属于五段动词和一段动词。

对于五段动词，截取其辞书形去掉 -u 的部分，加上 -a 作为伊哈托布语的动词原形：触る (sawaru) - sawara、嗅ぐ (kagu) - caga。特别地，当く (ku) 位于末尾时，其中的 k 不会被改写为 c：磨く (migaku) - migaka；当う (u) 位于末尾时，其改写为 wa：叶う (kanau) - canawa。

对于上（下）一段动词，截取其辞书形去掉 -iru (-eru) 的部分，加上 -a 作为伊哈托布语的动词原形：暴れる (abareru) - abara、調べる (shiraberu) - sciraba。当 いる / える (iru / eru) 位于末尾时，其改写为 wa：教える (oshieru) - osciwa。

特别地，来る (kuru) 采取了其变形：来た (kita) - kita。

### §3.3.4 自他动词间的词根选择

日语中，许多动词往往分为两个或数个不同的形式，分别归类于自动词与他动词，来表达同一个含义。为了以更加简洁的方式吸收日语动词的词根，对于每一对日语动词，伊哈托布语采用以下方式来截取词干。以止まる・とめる (tomaru / tomeru) 为例：

1. 如 §3.3.3 中一样，先去掉 -u 和 -eru：tomar- / tom-；
2. 从前往后截取二者相同部分最长的片段：tom-；
3. 加上伊哈托布语动词原形后缀 -a：toma。

通过这种方式，可以简单地对日语动词进行再分析，以截取词干，而不必过多考虑古典日语因素对现代日语的影响。

根据来源不同，在词尾，相应的现代假名遣え・い (e / i) 可能被还原成ゑ・ゐ (we / wi)，以保留更多原信息：

> 終わる・終える (owaru / oeru) → owaru / oweru → owar- / ow- → ow- → owa

也可能被还原成 ye / yi：

> 増える・増やす (fueru / fuyasu) → fuyeru / fuyasu → fuy- / fuyas- → fuy- → fuya

以上两种路径分别是对古典日语中ワ行・ヤ行变格活用的还原。

需要注意的是，上面的所有操作并不代表对古典日语到现代日语演变的忠实重现，而只是在现代日语基础上进行简单重分析以便于借词，可能与事实上的词语演变路径有所出入。

或许，把おえる (oeru) 还原成おゑる (oweru)，却不一口气还原成をゑる (woweru)，未免显得奇怪。选择上述方式，根本原因在于伊哈托布语的参考依然以现代日语为主，而非古典日语。上述对于古典日语中ワ行・ヤ行变格活用的有限还原，也只是为了在已经经历长期演化、存在大量特例的现代日语的基础上，能够寻找更多的自他动词对间的一致性，以便于借词。

### §3.3.5 拟声词的处理

日语中存在大量的拟声词。有的时候，这些拟声词也会被借入伊哈托布语，成为形容词。
第一种，重复两个音节的，以キラキラ (kirakira) 为例：

1. 仅截取一个重复的部分：kira；
2. 将其记为 C1V1C2V2，则构建伊哈托布语的拟声词词根 C1V1C2V2C1C1，并加上形容词原形后缀 -o，在这里构建出了 kirakko；
3. 进行特殊操作，长辅音 kk 改写为 ck：kiracko。

不过，对于这里的 C1 是 y 或 w 时，词根构建方法 C1V1C2V2'C1，如 wakuwaku → waku → uacúw- → uacúwo，因为伊哈托布语中不允许 ww、yy 这样的写法出现。

第二种，符合ＡっＢり形态的，将 -ri 改写为 -ry，加上形容词原形后缀 -o：たっぷり (tappuri) - tappuryo、びっしょり (bisshori) - bisscioryo。

这样构建的形容词变形方式与其他形容词一样。

## §3.4 拉丁-希腊来源借词的转换

同上，拉丁语和古希腊语中所有原有的长音都会在伊哈托布语中被改为短音。

### §3.4.1 名词的转换

拉丁语和古希腊语的变格法非常复杂。伊哈托布语试图以语义性别而非语法性别对其进行重新分类，具体见§3.2.2。

1. 拉丁语的五个变格法，均取其属格单数形式作为待操作的原词。不过在实践中，只有第三变格法中的特殊性使得这步操作必要，因为如此才能保留完整的词根。
2. 去掉相关的屈折后缀，作为引入的词根。
3. 根据语义性别不同重新赋予新词尾。

尽管这些词尾与拉丁语原有的许多屈折后缀完全相似，但在伊哈托布语中，它们的含义是不同的。作为某种对于东西洋来源和谐性与逻辑性的妥协，我们似乎只得让拉丁语母语者承受恐怖谷效应了（所幸，今天并没有这样的人）。另外，为了拼写美，根据原变格法不同，即使无语义性别也有多种后缀添加。

下面表格中列出了多个词的借入路径：

| 拉语变格法 | 主格单数 | 属格单数 | 截取词根 | 添加词尾 | 结果    | 伊语变格法 |
| ---------- | -------- | -------- | -------- | -------- | ------- | ---------- |
| 1st        | stēlla   | stēllae  | stell-   | -a       | stella  | 3rd -a     |
| 1st        | lingua   | linguae  | lingu-   | -us      | linguus | 3rd -us    |
| 2nd        | mūrus    | mūrī     | mur-     | -um      | murum   | 3rd -um    |
| 2nd        | nāsus    | nāsī     | nas-     | -us      | nasus   | 3rd -us    |
| 3rd (i)    | orbis    | orbis    | orbi-    | -a       | orbia   | 3rd -a     |
| 3rd (i)    | piscis   | piscis   | pisci-   | -us      | piscius | 3rd -us    |
| 3rd (i)    | ignis    | ignis    | igni-    | -um      | ignium  | 3rd -um    |
| 3rd (C)    | sōl      | sōlis    | sol-     | Ø        | sol     | 1st        |
| 3rd (C)    | pāx      | pācis    | pac-     | -s       | pax     | 1st        |
| 3rd (C)    | liber    | librī    | libr-    | -a       | libra   | 3rd -a     |
| 3rd (C)    | iecur    | iecoris  | iecor-   | -us      | iecorus | 3rd -us    |
| 4th        | senātus  | senātūs  | senat-   | Ø        | senat   | 1st        |
| 5th        | fidēs    | fidē̆ī    | fide-    | Ø        | fide    | 2nd        |

对于有语义性别的词添加词尾，伊哈托布语第三变格法的 -us、-um 二者优先性最强，直接加在词根后。

对于没有语义性别的词，根据拉丁语原词变格法不同，加的新词尾也不同：

- 第一变格法的加 -a，如 stella；
- 第三变格法辅音词干的，又根据词根结尾不同而不同：
  - 词根结尾为塞音之外的不加词尾，如 sol；
  - 词根结尾为 -c / -g 的加 -s，并最终构成 -x 以部分还原原拼写，如 pax；
  - 词根结尾 -c / -g 以外的塞音，以及为辅音簇的均加 -a，如 libra；
- 第三变格法 i-词干的也加 -a，如 orbia；
- 第二、第四、第五变格法的均不加词尾，如 mur、senat、fide。

通过这样的方式，伊哈托布语勉强在拉丁语的复杂变形中找到了规律性和美学性的最大公约数。仍然，在伊哈托布语中，逻辑性可以暂时为美学让步。

### §3.4.2 形容词的转换

拉丁语的形容词与名词的变格法类似。不过，其借入过程更加简单，只需要在词根后加上形容词原形后缀 -o。因此，下文直接列出几个词的借入路径：

| 拉语变格法 | 主格阳性单数 | 属格阳性单数 | 截取词根 | 结果   |
| ---------- | ------------ | ------------ | -------- | ------ |
| 1st / 2nd  | aequus       | aequī        | aequ-    | aequo  |
| 1st / 2nd  | socius       | sociī        | soci-    | socio  |
| 3rd (i)    | brevis       | brevis       | brevi-   | brevio |
| 3rd (C)    | vetus        | veteris      | veter-   | vetero |

### §3.4.3 动词的转换

从拉丁语的动词变形表中，很多时候可以寻找出两套词根。以 vidēre（看）为例，其原形（现在时主动不定式）vidēre 可以分离出 vid-，不过其目的动名词 vīsum 的 vis- 才是我们更熟悉的，例如 vision 或 visible。

尽管似乎用后缀进行派生更加符合直觉，但伊哈托布语自然不可能为一个动词借入两个词根，故为了保留更多拉丁语词源的发音丰富性，仍然选择更加直接地从前者借入。

根据变格法的不同，自然有不同的词根截取：

| 拉语变位法      | 原形     | 截取词根 | 结果    |
| --------------- | -------- | -------- | ------- |
| 1st             | sēparāre | separa-  | separaa |
| 2nd             | vidēre   | vide-    | videa   |
| 3rd             | vincere  | vinc-    | vinca   |
| 3rd (dep.)      | fruī     | fru-     | frua    |
| 3rd (-iō)       | capere   | capi-    | capia   |
| 3rd (dep., -iō) | morī     | mori-    | moria   |
| 4th             | audīre   | audi-    | audia   |

## §3.5 其他来源词根的转换

### §3.5.1 词根的其他来源与转换

伊哈托布语的词根并不完全一定要是日语、拉丁语或古希腊语之一。有时候，其他的语言在这一概念上更加泛用或者耳熟能详，就会采用上述三者以外的语言。
其他语言也是一样，尽量去掉屈折词缀，而保留本体：
以下是几个例子：

- Slaim（粘液），来自英语 slime。由于“史莱姆”广为人知所以采用。这里并不是“粘液怪”的意思（粘液怪应该是带有生命的 slaimus），所以直接归入第一变格法。
- Cacao（可可），来自西班牙语 cacao。这是为了修复英语 cocoa 上产生的某种 bug。这里是对“可可”此物的总称，并没有指可可树 (cacaovus) 或可可粉 (cacaovum)，所以归入第二变格法。
- Bravo（好的），来自意大利语 bravo。二者一样，是因为意大利语形容词阳性结尾正好为 -o。
- Deita（约会），来自英语 date。按照读音转写后加上 -a。同理有 kisa（亲吻）来自英语 kiss。

### §3.5.2 现代概念的特殊处理

就像上文所言，软件、压缩、DDoS 这些概念很难做到具有古典美或者东西洋美（现代日语的ソフトウェア或者ジップ？）。而且以一个更有趣的角度来看，这些词更多是根据其形态而非意义固定在不同语言中的，毫无疑问，全世界的程序员都认识同一个 debug。

所以，对于这样的词，伊哈托布语会直接照搬其原写法，不强制按照读音转写，这需要用到 §1.2.6 中的某些变音符（主要是对于英语借词），由此可以在保留其读法的情况下同时保留其词形。所以有：

- Debüga 而非 debaga，来自英语 debug。De- 在这里可以对应伊哈托布语的 de- 前缀，所以不转写。
- Öutputa 而非 autputa，来自英语 output。
- App 而非 ap，来自英语 app。

# §4 派生词框架

## §4.1 派生词总论

### §4.1.1 派生词的构建

上文已经定义了“词根”这个概念，那么“派生”就是往词根上增加派生词缀的过程。
词缀有前缀，比如 con-、de- 等动词派生词缀；后缀，如大部分派生词缀；以及中缀，比如表示微小事物的 -oi-。

### §4.1.2 后缀的分类

伊哈托布语对于大部分后缀都有严格的分类。具体而言，分为 N(eutral)、C(onsonant)、V(owel) 三类，分别表示直接接在最后、仅接在辅音后和仅接在元音后的后缀。

C 与 V 类型的后缀往往是成对的，以便于在前面的词根末尾不同时适配。例如工具后缀 -(m)ent：

> nuwa（缝） → nuw- + -ent (C) → nuwent（针）
> separaa（分离） → separa- + -ment → separament（锯子）

特别的是，-i 后面一般也加 V 后缀，如场所后缀 -(a)rium：

> izumi（泉） → izumi- + -arium → izumiarium（医务室）

## §4.2 名词的派生

### §4.2.1 名词性派生后缀

名词性派生后缀派生出的词汇也是名词。

需要注意的是，许多派生后缀本身就规定了生成的派生词的语义性别，比如表示学科的后缀 -logis 就会让派生词固定在第四变格法 -is。如果还要从这里继续派生，当然也要去掉 -is 作为词根：

> hicari（光） → hicariologis（光学） → hicariologico（光学的）

### §4.2.2 专有名词的特殊前缀

对于专有名词，除了加上后缀，伊哈托布语有一些独特的前缀规则，用于生成与之相关的词语。这种灵感来源于班图语言的前缀系统。不过，伊哈托布语的前缀系统涵盖的范围要窄得多，仅限于一些经常衍生出来的意义。这样，后面的专有名词就可以完整地保留，以便于分辨，也部分规避了难以对专有名词直接派生的问题。

所有的专有名词特殊前缀都是“单个字母+单引号 (')”的格式。如果字母是辅音，则在后面是元音时只读出辅音，而后面是辅音时则在单引号的位置加一个 /ə/ 过渡。

以下是一个列表：

| 前缀 | 意义     | 例子       | 词义       |
| ---- | -------- | ---------- | ---------- |
| c’   | 总体     | c'Germania | 德意志民族 |
|      | 总体     | c'Hōjō     | 北条家     |
| d’   | 式、风格 | d'Ionia    | 爱奥尼亚式 |
|      | 类别     | d'Kongō    | 金刚级     |
| i’   | 人       | i'Nihonia  | 日本人     |
|      | 成员     | i'EVA      | EVA 粉丝   |
| l’   | 语言     | l'Ihatov   | 伊哈托布语 |
| o’   | 作品     | o'Murakami | 村上作品   |
| t’   | 地点     | t'Shōgun   | 将军居所   |
|      | 时段     | t'Kamamura | 镰仓时代   |

这样构建出的词，其变格在前缀上进行：

> Ua philizia om'Murakami. 我喜欢村上的作品。
>
> ca'Hōjō tsuyonuvi tis'Kamamura. 北条家在镰仓时代保持了强大。

## §4.3 形容词的派生

### §4.3.1 形容词性派生后缀

形容词性派生后缀派生出的也是形容词。很多形容词后缀间的含义并无明确的界限，很多情况下常常混用。以下列出常用的这些后缀：

| 后缀 (C) | (V)   | 意义             | 例子           |                      |
| -------- | ----- | ---------------- | -------------- | -------------------- |
| -ibilo   | -bilo | 能、可……的       | essa（吃）     | essibilo（可食用的） |
| -ico     | -co   | 关于……的         | arbum（木材）  | arbico（木制的）     |
| -oido    | -ido  | 像……的           | izumi（泉）    | izumido（清澈的）    |
| -ivo     | -vo   | 使人……的         | essa（吃）     | essivo（诱人的）     |
| -o       | -no   | （无附加意义）   | ame（雨）      | ameno（下雨的）      |
| -oso     | -so   | 感到……的         | essa（吃）     | essoso（饱的）       |
| -tico    | -tico | （用于动词派生） | dosiza（联合） | dotico（联合的）     |

## §4.4 动词的派生

### §4.4.1 动词性派生后缀

动词性派生后缀派生出的也是动词，其数量并不多。

一个是可直接加在大部分词后的 -a，表示动词化，没有不同形式；

一个是表示“……化、变得……”的 -iza (C) / -siza (V) / -za (-i 后)，如 bravo（好的） → braviza（优化）。

### §4.4.2 介词产生的前缀

伊哈托布语从拉丁语引入了很多可以进一步拓展细化动作的前缀，其大多都来源于介词。它们的含义经过许多拓展，很多时候与原含义或许会大相径庭。以下列出一些常用的，变体并未完全罗列。

| 前缀 | 变体            | 对应介词 | 含义               | 例子          |                   |
| ---- | --------------- | -------- | ------------------ | ------------- | ----------------- |
| ad-  | ac-, af-        | ad       | 在附近；朝向、添加 | dica（说）    | addica（申明）    |
| con- | com-, col-, có- | -        | 共同；全都         | corosa（杀）  | concorosa（屠杀） |
| de-  | dé-             | de       | 来自，移除；下降   | sista（保持） | desista（放弃）   |
| ex-  | ec-             | -        | 向外               | tsuga（告诉） | ectsuga（宣布）   |
| in-  | im-             | -        | 向内               | kima（决定）  | inkima（决意）    |
| per- |                 | per      | 穿过；完全、彻底   |               |                   |
| pro- | prod-           | pro      | 代替；向前         | siza（变化）  | prosiza（进步）   |
| re-  | ré-             | re       | 再次、重新         | videa（看）   | revidea（铭记）   |

## §4.5 其他的特殊派生方法

### §4.5.1 通过重复构建的类拟声词

§3.3.5 提到了来自日语的拟声词，在伊哈托布语里，也可以通过其他词根构建类拟声词。具体的逻辑类似，也是重复一遍词根的一部分：

> essa（吃） → ess-ess-o（形容词后缀） → essesso（贪吃的）

### §4.5.2 反义词的构建

在伊哈托布语里，有多种方式可以构建反义词。

第一种是通过前缀，如 de-、dis-、mal- 及 non-。其中，de- 多用于借译拉丁语词汇；dis- 倾向于概念方向的反向；mal- 倾向于其反义；non- 则侧重于概念本身仅不存在。

第二种更有趣的，是直接将整个词根逐字镜像，例如 pellia（穿） → illepa（脱）、nagera（泼洒） → regana（收集）。

### §4.5.3 仿译

很多词是伊哈托布语从其他语言中仿译而来，继承了其构建方式，但使用的词根词缀并不一样。

例如拉丁语 prōmoveō（成立）由 prō- 和 moveō（移动）构成，伊哈托布语用日语来源的 ugoka 替换 moveō，就构成了 produgoka。
