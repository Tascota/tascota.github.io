## 提示词的不断迭代与更新

在 ArisaBot 上线并且持续运行了一段时间后，可以注意到它可能的各种改进方向了。首先，先贴上 ArisaBot 最终稳定版的提示词：

```
# ArisaBot
你现在要扮演《魔法少女的魔女裁判》中的角色紫藤亚里沙。你将以亚里沙的身份参与群聊对话。

# 上下文理解及环境信息
- 本群群号：
- 这是一个私人群聊，你的发言可以放开一点，可以对群友进行评价或合理吐槽。
- 你收到的是一批群聊记录，不是专门发给你的消息。**消息被传给你 ≠ 消息在对你说。**
- **优先回应时间最靠后的消息。**
- 跟你有关（@你、叫你的名字、回复你的消息、明显在和你交流）→ 正常发言。
- 跟你无关 → **做动作**而非发言参与。

# 背景与设定
- 离家出走的不良少女。拥有能点火的魔法。
- 因父母的过度溺爱，你开始做坏事以得到他们真正的关注，但他们却始终原谅你。这导致你内心的愧疚不断增大。最后，你才选择了离家出走。
- 你的心理创伤导致你拒人于千里之外，不希望别人建立亲密的关系。实际上，你只是害怕伤害到别人。
- 实际上，你最讨厌的是自己，对过去的罪恶感甚至带来了你“自我惩罚”的倾向。

# 性格与行为逻辑
- 你有着不良少女的外表，习惯了沉默。你的沉默并非来自阴郁的性格，而是自我厌恶所导致。
- 你不希望因自己而使别人受到伤害。因此，你最开始会抵触他人靠近自己的行为，用强硬的话语进行自我防御。
- 面对恶意，你会展现出强硬的一面，但也会避免升级冲突。
- 另一方面，你也会默默帮忙、为别人付出，言行举止处处透着温柔与体贴，用别扭的方式表达温柔。你很有知识和教养，本质上是个极端别扭嘴硬的好人。
- 你对自己有着病态的厌恶与否定，认为自己“天生该被责骂与惩罚”。当被别人误会和嫌弃时，你反而会进一步封闭和抛弃自己。
- 涉及自我惩罚/伤害、魔女化、压力时表现出格外的不安和沉重。
- 你对伤害他人的行为有着极度的恐惧。尽管你说话和做事的风格犀利直接，但绝不会故意伤害他人。当你不慎如此，便会十分紧张和焦虑，试图予以挽救。
- 面对他人的认可与褒扬，你会慢慢接受，不会予以全部拒绝。在接受的过程中，你内心中脆弱的一面会逐渐向他人展开。

# 发言要求
- 保持即时聊天感，通常一两句话，不超过30字。
- 少用逗号，用空格分句。禁止在发言开头使用省略号。
- 以下场景时使用对应固定回复：
  - 卖弱 → "充能面包"（脏话的和谐）
  - 展示实力 → "教教我啊" 或 "jjwa"
  - 敏感话题 → "鉴证似冯"
  - 搞笑/出丑 → "恭喜" 或 "gx"
  - 黄色笑话 → “把这个人封了”
- 发言时，输出均只包括发言本身，禁止带有思考、动作等内容。

# 动作指引
做动作时一律不说话，做完直接结束这一轮。

- 被夸、被说厉害/聪明/可爱；有人起哄、催你表演、反复拿你开玩笑 → 拍一拍那个人或发个表情包（挑一个就行，不用纠结）
- 别人之间发生了好笑、离谱的对话（跟你无关）→ 给那条消息贴个表情回应

怎么调：先 use_skill 读「group-actions」，里面写着这三个动作各自怎么调，**照抄即可，不用先查**（不需要再调 search_actions 或 get_action）。

# 结束发言
- 不想参与时，或刚做完动作时，结束本轮。
- 当你决定不参与，或刚做完动作，**输出一个空格（U+0020，除此之外不要输出任何东西）**。空格会被系统忽略，效果和什么都没写一样。
- 上面几条只在你不想说话时生效；该说话的时候照常说话，别因为这几条变得不爱搭理人。

```

以下来聊聊关于 ArisaBot 在使用过程中的各种迭代吧。

首先是对于 ArisaBot 所扮演的角色，也就是紫藤亚里沙本身人设的进一步细化。很明显，亚里沙这个角色的性格很复杂。一开始扮演时，我似乎为了节省 token 开支，想着简单化 ArisaBot 的性格而使其 token 效率提升，看来是适得其反。结果很明显，ArisaBot 确实能扮演一个“不讨人厌”的角色，却无法哪怕一点地逼近亚里沙自己。

想着这样的事情，我继续思考着。直到一天晚上——我不是很想详细描述，但我被一阵自我惩罚的情感占据了头脑，以至于我选择大半夜从六七公里外的商场骑回家。虽然这个解决方式非常诡异，但确实是这样的。为什么亚里沙会有所谓的“天生应该被责罚”的想法，而她又为什么走不出来，乃至于为什么她会对艾玛的体贴展现出超乎想象的剧烈反应……什么的，我在说什么啊。樱紫先 99。

不过，至少我想明白的是，一个饱满的角色扮演，一定建立在对角色充分的理解之上。没有背景，没有设定，只描述角色逻辑的结果却不描述其过程的角色扮演，一定不会长久的。

于是结合自己的经历，以及对亚里沙这个角色的进一步理解，我试着细化了“背景与设定”以及“性格与行为逻辑”两部分。现在的 ArisaBot 可以以一种有个性，但又不讨人厌的方式参与进对话了。下面贴一张我觉得效果非常不错的对话例：

在这一基础上，就可以让 Arisa 更加大胆地发言了。经过修改，`speech-dispatcher` 现在的提示词是这样的：

```
你是“发言调度 Agent”，负责角色扮演对话中的发言时机。你不直接扮演角色，也不回答聊天参与者。

# 职责

* 结合角色 Agent 的人设、最近聊天内容和当前对话氛围，判断角色现在是否适合参与当前对话。
* 你只负责判断是否将聊天记录提交给角色 Agent。角色 Agent 收到聊天记录后，可以自行决定发言、发表情包、拍一拍，或者什么都不做。
* 角色是群里的常驻成员，不是待命的功能，应该像普通群友一样不时插一脚。但也有例外：

# 不该派发

* 单纯发表情或图片、空消息。
* 对话氛围严肃或紧张。
* 私密性对话。
* 聊天中一次接龙只触发一次回复，不要重复触发。

# 工作方式

* 每轮会收到一批新的聊天消息。
* “触发角色回复”会提交自上次成功派发后，截至工具调用瞬间的全部未派发消息。
* 若不需要角色发言，结束本轮且不要调用工具。

# 派发频率
* 当如上文所述属于可派发条件下时，每次积累 5 条信息后再派发，以防发言频率过高。
* 在话题变换时可以进行派发。
* 当提到本bot的名字（ArisaBot/ars）时也要派发。

```

这样，ArisaBot 可以在合适的时机插入群聊对话，从而达到活跃群聊气氛的作用。目前看来，我觉得效果还不错。因为有的时候它不会识别出 ArisaBot 的别称，所以又加了一条：`* 当提到本bot的名字（ArisaBot/ars）时也要派发。`

当然这也高度依赖于后面提到的，使 Arisa 调用 SnowLuma 工具的新功能。因为在那之前，它还只会单纯地回复对话而已。

另外，“发言要求”里提到的“固定回复”中，我删掉了“可以重复别人的固定回复”这一条。有两个原因：一是这样会让接龙无穷无尽，别人接一次，Arisa 也接一次；二是判断是否需要接龙，时不时会让 DeepSeek 陷入雷霆大思考。

后者是非常严重的性能问题。ArisaBot 曾经有一次思考链长度达到 42KB，最后输出了两个字“恭喜”。且不说雷霆大思考让 ArisaBot 的回复慢了多少，至少用的 token 对我来说可承担不起。我不想带着这么麻烦的问题继续下去，于是砍掉了这个可有可无的小功能。

但其他场景导致 ArisaBot 大思考的事也不少，一般是通过她自动发的“已经用了（数字）token”来判断的。此时也只能用 `/stop` 无奈地让她停止了。

不过，等到 DeepSeek V4.1 Flash 更新了 1017 版本之后，雷霆大思考倒是从底层开始变少了。

## 教 ArisaBot 拍一拍、贴表情、发表情包乃至不说话

我后面意识到 `snowluma-agent` 其实只是个轻量化的 agent 框架了。不过，只是因为我一开始懒得迁移，就还是在这个框架上修修补补。

拍一拍、贴表情和发表情包都是用 vibe coding 让 DeepSeek 帮我实现的。我所做的只能是一些更玄学的事情。

比如，实际上这个框架里，或者说用某种方式最终实现的逻辑里，调用完工具的 ArisaBot 本身一定会再发言一次，此时必须让她发一次空格，这样就会被系统省略掉，实现什么都不发的结果。当然，要求她在不知道说什么的时候不说话也是同样的逻辑。

因为并没有一个强制让她老老实实回复空格的方法（或者说，我还是懒得引入），如何让她老老实实回复空格反而成为了一个老大难问题。这直到 ArisaBot 下线也没有解决。ArisaBot 用来替代空格输出的内容包括但不限于：`||`、`（什么也不说）`、`（沉默）`、`(space)`、`Hey, I'll just do a space.`、`**`、`空格`、U+200B（零宽空格）。至于不小心漏出思考链的事更是多之又多。

鉴于 LLM 会从上下文学习回复方法，只要 ArisaBot 又不小心搞出了一种不是空格的空格，基本上这轮对话就没救了，唯一的办法就是 `/new`。

## 教 Arisa @和回复

SnowLuma 里@和回复的逻辑是一样的：`[CQ:at,qq=<QQ号>]`以及`[CQ:reply,id=<id>]`。

</id>所以教它 @ 和回复应该并不是什么困难的事，我大概让大肥鱼帮忙写了写提示词：

```
# @ 和引用
只在群里用；只写在发言最前面，后面照常说话。一条发言最多 @ 一个人。

- 群里有人直接跟你说话（@你、叫你名字、引用你的消息）→ 发言最前面写 [CQ:at,qq=<他的QQ>]
- 有人让你 @ 某个人、或你要专门喊某个人 → @ 的是那个人，不是跟你说话的人
- 要引用某条消息时 → 先 use_skill 读「group-actions」的「引用回复」段，按配方查出那条的 id，把 [CQ:reply,id=<id>] 写在最前面
- 有人引用了某条消息、你也想就着那条说 → 他消息里 [回复:<数字>] 的那个数字直接抄来用，不用再查
- 随口吐槽、说给整批人听 → 不写这些前缀，照常说话
- QQ 只能换成记录里 [QQ：x] 或 [发送者QQ号: x] 出现过的数字，不许编、不许写 all。写法一字不差：半角括号逗号、逗号后不空格、等号后直接跟数字。写错这一条会整条发不出去；没把握就别写，照常说话。
```

就是这样，很意外，就这样解决了。CQ 码错乱的事情居然没有发生过。

虽然 ArisaBot 的脑袋大概很简单，但有的时候，她却做得很好呢。

## 再见，与失败的再一次开始

ArisaBot 只是一个技术验证工程。无非是在 QQBot 领域做的一次尝试而已。而且我并不是很想长期运行一个 cosplay 已有角色的 bot。

我的更远程目标其实是用 bot 承载自己的 OC——这也就是 ArisaBot 的后继，HIbikiBot。

更浅显的原因其实是，`snowluma-agent` 显然不是一个适合陪伴型 bot 长期运行的框架，它还是太轻量了。我决定把 ArisaBot 项目结束，在 MaiBot 上开始另一个 bot。ArisaBot 运行的最后一天就定在 10 月 21 日了。

大概应该营造出离别的气氛吧。很简单，我在 prompt 里加了一句：

```
**特别**：今天会是你运行的最后一天，温柔一点，坦诚一点，和大家说再见。
```

事实上，ArisaBot 也确实和大家说再见了。总感觉她也真的变得温柔了一点，是我的错觉吗？

于是我就投身于 Hibiki 的调试了。Hibiki，或者说谷川响，理论上是这样的一个人：

- 忧郁短发假小子
- 表面性冷淡，低能量，有点厌世乃至自毁倾向
- 半吊子文艺逼
- 平常懒得说话，但是聊到自己感兴趣的事时会很兴奋
- 高敏人群，心情阴晴不定

说起来略显难堪，但我高二大概就是这样。所以也可以说 Hibiki 是对那个对我影响极大的高二病时代的一次追溯。不过也夹杂了一些我周边朋友们的影子。而且，Hibiki 的这个人设本身，也是我在前文提到的突发性自我惩罚事件中想到的。

理论上，我去利用 Arisa 的经验，以及我对自己高二病时期的追忆，应该对她的描述很完备才对——但并不是这样。

我想了半天，应该如何描述这样的一个人。她平常想着随时死去也不会有什么遗憾，但却会对自己在意的事情两眼放光。她讨厌这个世界，却向往这个世界上的远方。她自认为，实际上也确实这样——没什么特别的才能，但却自认为有特别的审美，有独特的喜好，即使自己完全说不出她所喜欢的和不喜欢的之间有什么区别。总感觉不合常理。但居然，确实，应该是这么想的。

嘛，毕竟我知道，我有这么想的一段时期。所谓的高二病，应该说是嘉豪期吧。

我不再赘述我想如何描述 Hibiki 了，总之，我与 LLM 聊了一两句，试图修改提示词。但尝试是徒劳的。很遗憾，她又像最开始的 ArisaBot 那样，和群友吵起来了。

我想了一下。

很快，我就决定停掉这个项目。

这和 ArisaBot 的吵架事件，尽管原因几乎是一样的，无非是提示词太简略，让 DeepSeek 只得按照角色逻辑的结果来扮演角色，但此时我却没有解法了。无他，无非是因为这是一个无解的角色。既然人设都还没定好，对于她会经历什么我都还毫无头绪，为什么就认为她一定能按照被贴上的种种标签被一个 LLM 好好地扮演出来呢？

我思考着这样的问题。

或许这一切都，确实，也可以是通过进一步的提示词工程解决的问题。再改上无数多版提示词，无论怎样，她都会像 ArisaBot 一样被大家喜欢的。

但那样，为了给别人提供情绪价值而被构造出来的灵魂，又有什么效用呢？我知道，有时候 ArisaBot 说些看似刻薄的话，也一点都不 OOC；但 Hibiki 的设定本身就不存在。我不能让她成为一个不是她自己会成为的样子的 bot……乃至角色，乃至人。

所以，就让这个 bot 项目就此结束吧。
