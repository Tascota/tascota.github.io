<ol>

<li>j / q / x 因尖团音不同而分别转写。</li>

<li>对齐齿呼的音节，在 j / q / x 后，在声母和韵母间可能会添加一个 i。</li>

<li>对开口呼和合口呼的音节，在 zh / ch / sh / r 后，在声母和韵母间可能会添加一个 i。</li>

<li>零声母的开口韵音节前添加 ng。</li>

</ol>

以下为原来的几个例子：

兰州：Lanceu；太原：Taeiüen；景县：Chimscien；康定：Camtim。

利用这个规则可以得到：

理塘：Litam；义乌：Iu；中山：Comscian；扬州：Iamceu。

<br>

其方位格加上 -(C)ensis 即可。

<section id="modern">

第二种总结自现代的拉丁语维基百科。其转写方法不一且来自不同来源，所以很有可能从头到尾都与上面梵蒂冈的转写不一样。当然也有直接写拼音的，但为了代入感考虑我们还是不这么做。

<br>

但总体来讲可以从上面的规则中改变几点：

<ol>

<li>韵母转写以 u 开头的，前面声母转写为 c 的可以写作 q，例如贵州 Queichea。</li>

<li>以辅音字母结尾的可以再添加一个 -ia 词尾，让它适用第一变位法，则有海南 Hainania 与河南 Honania，“河南的中心”即为 centrum Honaniae；也可以添加 -a，例如福建 Fochiena（这个转写把“福”转写作了 fo）。</li>

<li>-ng 结尾的韵母可能会直接写作 n，例如广东 Quantunia。</li>

<li>j、q、x 可能转写作 c / q，例如江西 Quiansia；也可能为 ch 甚至 k。</li>

<li>词语开头的 sh 可能转写作 x，例如山东 Xantonia、陕西 Xensia、陕西 Xansia。</li>

</ol>

以下再列出几个维基百科采用的转写来扩充想象力：四川 Suchuen；浙江 Cechiana。

<br>

如果是城市，转写后以 u 结尾的可以改成 um，以适用第二变格法，如福州 Focheum、广州 Quancheum、成都 Chingtum、杭州 Hancheum。

以辅音结尾的可以直接加 -um，如南京 Nanchinum、南昌 Nancianum、济南 Cinanum、太原 Taiyuenum；

也可以加 a 来适用第一变格法，如南昌 Nancianga、贵阳 Queiyanga；

还可以加 vum 来适用第二变格法，如上海 Sciamhaevum。

总之，以看起来像拉丁语的地名为第一要点，例如再试着做几个转写：南宁 Nannimum / Nanninga；长春 Chamchunum；深圳 Xencenum，“深圳的企鹅”可以写成 spheniscida Xencenī。

</section>
