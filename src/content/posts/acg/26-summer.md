## Tier A

### 天幕のジャードゥーガル / 穹庐下的魔女

Bangumi 7.96 / Tascota 8.0

一部能够令人感受到用心的作品。

能在尊重历史的基础上，将史书中只有寥寥数笔记载的小人物的一生扩写得波澜壮阔，无疑比基于历史事实的改编更难。毕竟普通的历史剧有历史作为借鉴，但想把本没有的故事补写出来又逻辑自洽，就不知要花多少心血了。制作组对蒙古文化的细致考究，结合历史本有的壮阔感，也使得这部动画的观感非常出色。

也是作为一部历史剧，所有观众都知道剧中人物的结局。例如，法蒂玛和脱列哥那在历史上评价如此不佳，下场又如此不堪，不禁会让我对此时她们的复仇感受复杂不已。但可能这就是专属于历史的醍醐味吧。

### ヤニねこ / 尼古喵喵

Bangumi 7.51 / Tascota 8.0

这无疑是 21 世纪最伟大的动画！就算不上什么后现代价值，烟猫也无疑是对久缺描绘的那种挂壁生活描写得最好的动画之一了。更何况光是搞笑这一块，它就已经非常不错了，完美地治好了人们的性避讳、屎尿屁避讳、下三路避讳。观看十二集，烟猫治好了我的精神内耗。

虽然我可能是个很没品的人，但屎尿屁笑话放在合适的地方就是很好笑。比如说，之前间谍过家家剧场版的屎尿屁笑话就让我很无语，因为它是个合家欢动画。但毕竟烟猫是个这样的动画，像全城直播放屁反而变得很搞笑了。（大概不是搞笑，而是令人无语得好笑？和关西喵的原理一样。但确实笑了吧。）

在这么无厘头的动画里，又加上药猫这种人设，就实在太超标了。时不时让药猫真情实感，又让烟猫性猫这种大愚若智的人去治愈她……之类的。最打动人的无疑是药猫消沉的时刻了。她与房东开车去兜风的那一段，甚至都有种 postpunk 的美学体验。

啊呀呀，应该放个后朋当 in 的。一定很适合吧。

Bangumi 7.22 / Tascota 7.5

在这个季度，能看到这么认真的动画还真是不错啊。

偶像番的规矩不能坏。规矩立住了，马戏团才能长远。普通是普通了点，但看得不烧心。

而且就连主角一个一个解决成员的任务，到最后再解决主角自己的问题，这样的安排都很像偶像番。乃至魔术师真的会魔法，和大象玩的真的能通灵，很神奇吧。

到最后，钉宫团长也没噶，马戏团的大家也继续上学，我们都有光明的未来。虽然马戏团马上就要退版本了就是了。

大概就是这样，大家好好上学好像才更合理的样子。

### さよならララ / 再见菈菈

Bangumi 6.53 / Tascota 6.5

总感觉是一部很有平成气息的作品。不说昭和，大概是因为人设的风格吧。之前有人看到说 mari 像从真夜中 mv 里出来的，深有同感。就是那种没有什么特别的锚点，但就是很抓眼的感觉。

另外，OP 大概也是一个因素，让人想到平成时代的什么爱情剧的主题曲了。

不过，总感觉我能够给菈菈这部番的好评也就限于这几点了。不得不说，最后几集的剧情，不限于什么意义不明，我算是根本没看懂。

还是很怀念前几集的菈菈的感觉呢。像第一集那种童话故事式的娓娓道来，前几集那种一步步见证小鱼走进温暖的人类世界，甚至乎后面她与 luca 相遇等等，都让人感觉一切正在走入正轨。但作为原创番，那种无法预测的命运之舞台的结局，就必然有着不可避免的主线。

WEP 的和 LycoReco 的那种感觉还历历在目……。所有人都被天意侵蚀了啊。

有的时候，就是会让人感觉“那种东西还不如没有的好”。真实的爱就是无言的爱呢。最后，mari 真可爱。

### きみが死ぬまで恋をしたい / 与你相恋到生命尽头

Bangumi 6.63 / Tascota 6.0

思来想去，虽然恋死的表面上看着很舒心（至少没有其他真百作那些普遍贫瘠的作画和不足的经费），画风好看绘柄也美丽，但总是让我提不起多大兴趣。

还是只就动画来说，恋死的主 CP 应该是 sheena 和 mimi，但这两对在动画的这部分，完全是母女关系而不是情侣关系啊。反正我个人是挺难把现在的她俩视作女同的。

另外一个发刀的副 CP 是 seiran 和 ali。但看到 seiran 退场的那一刻，我想的是，这部番里居然真的有人领便当了。只是单纯挺意外的。因为，seiran 退场的部分做得实在挺草率的，不像是四个主角之一退场时的感觉。有原作党指出这里改编了，反正我觉得动画里跑树上思考人生然后被一击干掉太奇怪了。很草率。

不过，seiran 离开的剧情，到后面通过 ali 不断地回忆与补刀，让人感觉上能够代入了。甚至最后一集还完全用来塑造副 CP，最后结果上倒是让人感觉挺不错的。至少这一对我认为很有感觉。

总之，着笔比较多的主 CP 没有恋人感，副 CP 又比较草率（虽然后面救得不错），让我总感觉比较难磕。

最后的最后，我还是想说，恋死这部动画对于背景与世界观过度的“避免交代”的倾向是个败笔。

虽然这也使得剧情能够聚焦在少女们的内心世界，让情感更加细腻，也不至于去写什么捉急的政治戏，但完全不去交代世界观，反而让这一切的故事像一个空中楼阁。我不知道恋死是不是本质上在反战，但至少看动画，只能看出少女们莫名其妙地就要上战场，然后莫名其妙地被杀。就算只是对“学校使得他们能活下去”这样的方面多正面描写一下也不错。并不是说一定要去写世界观，至少也让她们经历的一切有个理由吧。

至少，我觉得完全没有缘由，反而更让本就比较着急的 CP 感失去了必须存在的理由，没有了那种命运感和“一定只能是她们俩”的感觉。更何况 sheena 和 mimi 这一对成立的理由，就是 mimi 对生命、对人、对世界的理解不断深化的过程。在这个设定下，却不去写生命消逝、世界崩坏的缘由，哪怕只是一点点，实在让人很难接受。

最后，恋死的绘柄确实挺好看的。

### BanG Dream! ゆめ∞みた / BanG Dream! YUME∞MITA

Bangumi 4.72 / Tascota 4.0

唉，炒作。

虽然 viola 这个角色塑造得不错，也很有热度和话题度，但她并不是梦限大的一员啊。武士道你到底在想什么。

结果到最后，梦限大的每个人还是只剩刻板印象，包括但不限于 U 咩哇帕哇、大卫带、啥子、豆包和 viola 花痴。

要塑造薇藤就给我塑造好了啊。要是最后能让这俩人真的来场酸酸甜甜的认真的分手，我就不会这么难受了。结果从各种情况下都在塑造 myk 是真的喜欢 vol，而且 vol 还有可能是双箭头，结果又在 bdon 里搞设定回撤，又让 myk 画星星，真是蠢死了。还搞的 myk 的风评一度极差。

至于别的角色，arl 和 ritsu 因为有篇幅，所以塑造尚可，nnk 和 yuno 完全查无此人。反正我是没啥印象，只记得一个是啥子兔子，一个是豆包。这真的是乐队宣传片吗。只能说是混个眼熟吧。

但是吧……但是。追梦限大这种番是真的挺有意思的。毕竟很难有番能跟邦一样有这么观众一起看（赤石），更别提还有那么多二创了。总之，体验其实很不错，虽然主要是场外的。

你说质量怎么样，值不值得看，我说体验感很好，大概现在的邦邦就是这样。虽然 bdon 我已经决定退坑了。
